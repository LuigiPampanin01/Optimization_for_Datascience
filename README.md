# Optimization for Data Science | Graphical LASSO Regression 

## Environment setup

In the project folder, run:

`conda env create -f environment.yml`

and then 

`conda activate ds_optim`

Go to the [solutions](assignment.ipynb) notebook and run.
> **NOTE:** You might need to restart your IDE if the new environment is not found
